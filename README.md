# Messaging App

A lightweight browser-based messaging app built with vanilla HTML, CSS, and JavaScript.

## Features

- Send messages with a name and message body.
- Auto timestamps each message.
- Persists the latest 100 messages in `localStorage`.
- Responsive layout for desktop and mobile.

## Run locally

```bash
python3 -m http.server 4173
```

Then open <http://localhost:4173> in your browser.
